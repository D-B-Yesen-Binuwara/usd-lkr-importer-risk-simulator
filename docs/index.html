USD/LKR Importer Risk Simulator

This page describes the current project status. It is a static information page, not an exchange-rate simulation.

Current project stage

The Python pipeline prepares CBSL USD Telegraphic Transfer selling-rate observations, adjacent-observation log returns, a 2019–2024 calibration window and an available 2025–2026 evaluation window.

The Python project fits a calendar-gap GBM and a bounded two-state quote-step Markov volatility model to 2019–2024 selling-rate returns. A hypothetical USD 100,000, 90-day invoice run calculates LKR costs and upper-tail risk. Training-window, volatility and 252-session clock comparisons plus replicated convergence checks are now available in Python. Interactive controls are not implemented yet; source CSV reuse terms remain unresolved.

Snapshot

  • 3,381 usable USD quotes, 2010-05-07 through 2026-11-19.
  • 1,445 calibration quotes and 1,444 in-window returns.
  • 457 evaluation quotes and 457 evaluation returns in the supplied snapshot.

These are data-preparation counts, not simulated forecasts.

Run locally

Install dependencies from requirements.txt, then run python -m src.prepare_data from the repository root. Run python -m pytest -q to execute the included checks.
