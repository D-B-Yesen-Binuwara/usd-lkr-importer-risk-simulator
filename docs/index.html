About and how to use

  1. Choose invoice size, days to payment, volatility multiplier, path count and seed.
  2. Press Start. Pause stops new simulation batches; Resume continues the same seeded run. Reset clears results and restores defaults.
  3. Compare expected payment, upper-tail VaR/ES and budget probability. Repeat with changed assumptions to explore sensitivity.

The exact calendar-time GBM transition is S(T)=S(0) exp(alpha*T + sigma*sqrt(T)*Z), where T=days/365. Each browser run draws independent standard-normal shocks using a seeded browser generator. The same numeric seed need not produce NumPy's identical random sequence; parity is checked with explicitly supplied shocks instead.
